# Known issues and cautions (do not silently correct)

1. **G04 printed best-family label conflicts with its own ranking.** The completed thesis-derived G04 table lists `WeightedAnchor_NoBias_alpha0.4` as best at 70.19 mean BACC, but its final print line says `Exploratory best family: SimCLRAnchor_NoBias`. The executed G05 table confirms the 70.19 value and ranks weighted-anchor first. Treat the printed G04 selection label as inconsistent; inspect the original code before using it as evidence.
2. **Test-set post hoc comparison.** G03/G04/G05 compare many families on test-related labels. Model choice made from these comparisons is exploratory, not a pristine test-validated model selection.
3. **J8/J9 attribution/leave-one-out discrepancy.** Notebook narrative summaries attribute largest contributions/LOSO changes differently (J8 mentions Rotation vs J9 manuscript text mentions FusionConcat under its calculation). Distinguish definitions/samples and reconcile before citing any single source-attribution claim.
4. **Different protocols, nonidentical folds.** Original J1 test and N01 validation cannot be used as if they are paired observations, and baseline results cannot be directly compared as effects caused only by lesion grouping.
5. **Some upstream training notebooks and Kaggle model binaries are missing.** R02/R03 pretraining and older thesis training outputs are dependencies. The original trained checkpoint directories are not bundled.
6. **Earlier G01 source matching is incomplete for renamed J1 images.** The executed G01 audit reports zero directly matched G02-A original test IDs, while later G02-A uses content-based matching to identify 2,239 HAM/BCN original test images. Cite the G02-A content audit for that cohort, not the earlier direct-ID count.
7. **Publication metadata outstanding.** Authors, affiliations, contact, ORCID, copyright/license and funding/ethics/data reuse permissions must be checked by the repository owner before public release.
8. **Notebook media and supplied research figures.** Embedded notebook image/HTML outputs were removed (code and numeric/text outputs retained), but **12 author-supplied figure PDFs and GitHub-rendered PNGs are now included separately**. Two XAI figures reproduce dermoscopic source images whose redistribution permissions require verification. These public notebooks are not byte-for-byte archival originals.
9. **Supplementary confusion matrix mismatch.** `figure07_confusion.pdf` has cell counts different from `figure07a_image_level.pdf` and `figure07b_lesion_aware.pdf`. The latter two reproduce G05 WAS-SSL full-cohort BACC; the former is archived separately without model attribution.
