# Code-license decision

No software license has been applied automatically. A GitHub repository without a license normally reserves all rights.

If all code contributors approve, **MIT** or **Apache-2.0** may be suitable for the authors' original code. However the dataset images, pretrained checkpoints, model licenses and third-party software each have their own terms; licensing your own code does **not** relicense those materials.

Confirm institutional/collaborator ownership before adding a `LICENSE` file. Choose your license via GitHub's standard license chooser after approval.
